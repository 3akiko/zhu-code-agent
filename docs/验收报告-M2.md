## 开发中发现并修复的问题（记录在案）

1. **bash 大输出死锁**：输出超过管道缓冲区（~64KB）时，先 `waitFor` 后读输出会让子进程写满管道阻塞、假超时。→ 改为独立线程边读边等（`BashTool` 并发读 + kill 后取回）。
2. **raw 单键权限确认在受限 PTY 不生效**：实测 tcsetattr 未真正切换原始模式（按键被行缓冲、无法即时读取）。→ 按变更控制（spec F3/AC3 已记录）改为「输入 a/d/s 回车确认」，跨终端稳定，安全语义不变。
3. **macOS /var↔/private/var 符号链接**：PathGuard 根目录与候选路径统一 realpath 后比较，避免平台符号链接误判越界。
4. **mock 服务器竞态（测试基建加固）**：全量测试偶发 `lastRequestBody` 空列表异常 → MockHttpServer 改为轮询等待请求体（消除偶发，复跑稳定）。
