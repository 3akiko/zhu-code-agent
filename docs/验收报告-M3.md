## 开发中发现并修复的问题（记录在案）

1. **权限模式参数大小写不匹配**：`handlePermissions` 把命令整体小写化后与驼峰常量（`acceptEdits`/`bypassPermissions`）比较，永不匹配 → `/permissions acceptEdits` 被误当查看。→ 统一小写比较（真机冒烟发现，2026-08-09）。
2. **review P2-1 `/plan` 不落盘**：handlePlan 各出口未 `saveSession()`，异常退出丢计划上下文 → 五处出口统一保存。
3. **review P2-2 覆写大文件全量读内存**：`WriteFileTool` 覆写前无上限 `readString` 旧内容（绕过 10MB 快照上限）→ 超 10MB 跳过 diff 只返回覆写摘要。
4. **review P2-3 纯换行差异不可见**：`DiffGenerator.splitLines` 丢弃结尾空行 → 仅增删末尾换行的 edit 显示为空 diff → 保留结尾空行并补单测。
5. **review P3 快照双重全量读取**：`FileHistory` 每次快照 `nextId()` 与 `append()` 各 `load()` 一次 checkpoints.json → 合并为一次 load 内计算 id。
