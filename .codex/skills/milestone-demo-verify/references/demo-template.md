## 引导消息编写要点

- **显式点名工具/能力**：`用 task 工具派一个子任务…` / `用 write_file 创建…`（否则模型可能不触发）。
- **给足上下文**：说明文件路径/内容/期望输出，减少模型自由发挥偏差。
- **一个场景聚焦一个验证点**：主链路 / 并行 / 权限 / 中断分开，避免混在一起难定位。
- 需要时先准备种子文件（如 `a.txt`），让场景可复现。
